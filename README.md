# Student Task Tracker

A simple web application designed to help students track their academic assignments, manage due dates, and organize priority levels.

## Features
* Add tasks with title, subject, due date, and priority level.
* Persistent storage using Browser LocalStorage so tasks remain after refreshing.
* Delete completed tasks.

## How to Run
1. Clone this repository or download the project files.
2. Open `index.html` directly in any web browser (or use VS Code's **Live Server** extension).
3. Start adding and managing your tasks!
